# Caintlyn-Linux-Rice
My first ever linux rice. 


## Programs
| Program | Function |
|---------|----------|
| hyprland| window manager |
| waybar  | status bar |
| kitty   | terminal |
| wofi    | app launcher |
| hyprshot| screenshots |
| thunar  | file manager |
| swaybg  | wallpaper |
| swayosd | on screen display |
| swaync  | notification and control panel |
| fastfetch  | cool statistics |

## Keybinds
| Keybind | Function |
|---------|----------|
| super + C | Close app |
| super + M | Exit hyprland |
| super + F | Full screen toggle |
| super + V | Toggle float window |
| super + Q | Open terminal |
| super + R | Open app launcher |
| super + E | Open control panel |
| super + shift + S | Take screenshot |
| super + arrows | Change active window |
| super + 1-0 | Change active workspace |
| super + shift + 1-0 | Move window between workspaces |
